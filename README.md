## 为什么需要它

Windows 11 的开始菜单磁贴布局（分组、顺序、固定的应用）保存在一个系统文件 `Start2.bin` 里。
每次重装系统后，这份布局都会丢失，需要手动一个个重新固定、重新分组——非常繁琐。

本工具把这个文件连同**系统版本信息**一起备份下来，重装后再一键还原。

更进一步：重装后布局虽然恢复了，但**没装的软件磁贴会「灰掉点不开」**。
本工具会在备份时顺手记录「你固定了哪些应用」，重装后一键核查，**列出还缺哪些软件、以及它们原来的安装位置**。

## 功能一览

| 功能 | 说明 |
|---|---|
| **备份当前布局** | 一键保存 `Start2.bin`，附带系统版本、文件大小、MD5、文件头等元信息 |
| **一键恢复** | 恢复前自动生成「回退点」→ 结束开始菜单进程 → 覆盖写入 → 重启资源管理器，立即生效 |
| **检查缺失应用** | 读取备份中的应用清单，核对当前系统，三档结果：缺失 / 需手动确认 / 已存在 |
| **备份列表** | 图形化列出所有备份点，显示时间、系统版本、文件大小；支持选中高亮 |
| **删除备份** | 每行右侧「删除」按钮，带危险确认弹窗，删除前明确提示 |
| **跨版本保护** | 备份与当前系统 Build / 版本不一致时，恢复前弹窗警告 |
| **自动回退点** | 每次恢复前自动把当前布局存成 `rollback_` 备份，出问题可撤回来 |

## 快速开始

### 方式一：直接使用 exe（推荐）

1. 下载 `开始菜单备份工具.exe`。
2. 双击运行，无需安装 Python 或任何依赖（单文件打包，约 19 MB）。
3. 建议把 exe 放在一个固定文件夹（如 U 盘或云盘同步目录），**备份数据会存在 exe 同级的 `backups\` 目录里**。

### 方式二：运行源码

```bash
# 1. 建议使用虚拟环境
python -m venv venv
venv\Scripts\activate

# 2. 安装依赖
pip install customtkinter pillow

# 3. 运行 GUI
python startmenu_gui.py
```

> 仅需 `customtkinter` 和 `pillow` 两个第三方库。
> 用到的 `Export-StartLayout`、`taskkill`、`explorer` 均为 Windows 系统自带。

## 使用流程

### 第一步：重装前 —— 备份

1. 双击运行 → 点 **「备份当前布局」**。
2. 备份成功后，`backups\<时间戳>_build<版本号>\` 目录里会生成三个文件：

| 文件 | 内容 |
|---|---|
| `Start2.bin` | 开始菜单布局本体 |
| `info.json` | 备份时间、系统版本、Build、文件大小、MD5、固定应用数量等 |
| `pinned.json` | **固定应用清单**（应用名 + 类型 + 快捷方式路径 + 是否系统内置） |

3. 把整个工具目录（含 `backups\`）拷到 U 盘 / 云盘带走。

### 第二步：重装后 —— 恢复布局

1. 把工具目录拷回新系统（放在和原来相同或不同的位置都可以）。
2. 双击运行 → 在列表里**点选要恢复的那份备份**（会整行蓝色高亮）。
3. 点 **「恢复所选备份」** → 弹窗确认（若跨版本会额外警告）→ 确认。
4. 工具自动执行：生成回退点 → 结束开始菜单进程 → 覆盖写入 → 重启资源管理器。布局立即恢复。

### 第三步：核查还需要装哪些软件

1. 选中刚才那份备份 → 点 **「检查缺失应用」**。
2. 弹出结果窗口（长清单可滚动），例如：

```
备份中共有 13 个固定应用。

❌ 缺失（2 个，重装后需重新安装）：
   · 网易云音乐
       原路径：%APPDATA%\Microsoft\Windows\Start Menu\Programs\网易云音乐.lnk
   · Typora
       原路径：%APPDATA%\Microsoft\Windows\Start Menu\Programs\Typora.lnk

⚠️ 需手动确认（1 个，商店 UWP 应用）：
   · SomeApp_8wekyb3d8bbwe!App

✅ 已存在（10 个）。
```

3. 按清单把缺的软件装上，磁贴即可重新点亮。

## 技术原理

### 1. 布局文件在哪

```
%LOCALAPPDATA%\Packages\Microsoft.Windows.StartMenuExperienceHost_cw5n1h2txyewy\LocalState\Start2.bin
```

工具会自动搜索 `Microsoft.Windows.StartMenuExperienceHost_*` 开头的包目录，优先取标准后缀 `cw5n1h2txyewy`。

### 2. 「缺失应用清单」的突破口

`Start2.bin` 在 Windows 11 中是**加密存储**的，直接扫描只能得到乱码，无法读出应用标识——
所以**不去逆向它**。

工具的替代方案是利用 Windows 自带的 `Export-StartLayout` 命令：在 Windows 11 上它导出的
**不是 XML，而是一份明文 JSON 的 `pinnedList`**，直接列出所有固定到开始菜单的应用
（桌面应用是 `.lnk` 快捷方式路径，商店应用是 AUMID）。

于是判断逻辑变得非常干净：

> **重装后软件没装 → 它对应的 `.lnk` 快捷方式就不存在 → 判定为「缺失」。**

### 3. 三档核对结果

| 档次 | 判定依据 | 含义 |
|---|---|---|
| ❌ **缺失** | 第三方 `.lnk` 展开后文件不存在 | 需要重新安装（附原快捷方式路径） |
| ⚠️ **需手动确认** | 类型为 AUMID（商店 UWP 应用） | 无法用路径判断，提示用户自行核对 |
| ✅ **已存在** | `.lnk` 存在，或系统内置应用（Edge / 记事本 / 计算器等） | 重装后自动恢复，不会误报 |

内置应用通过一份 `BUILTIN_LNK_NAMES` 映射表识别（如 `Notepad → 记事本`），并在结果显示中
保留中文名，更直观。

### 4. 恢复的可靠性设计

- **恢复前必存回退点**：把当前布局另存为 `rollback_<时间戳>`，随时可撤回。
- **跨版本拦截**：备份的 `CurrentBuild` / `DisplayVersion` 与当前系统不一致时，恢复前弹窗警告。
- **进程处理**：先 `taskkill` 结束 `StartMenuExperienceHost`，写入后再重启 `explorer.exe` 使布局生效。

## 目录结构

```
开始菜单备份工具/
├── 开始菜单备份工具.exe      # 【主交付物】打包好的图形界面程序（单文件，免安装）
├── startmenu_gui.py          # GUI 源码（customtkinter）
├── generate_icons.py         # 图标生成脚本（Pillow 自绘 SVG 风图标）
├── icons/                    # 图标资源
│   ├── app.png               # 标题图标（蓝白四宫格）
│   ├── app_icon.ico          # exe / 窗口 / 任务栏图标（多尺寸）
│   ├── backup.png            # 「备份」按钮图标
│   ├── restore.png           # 「恢复」按钮图标
│   ├── folder.png            # 「打开目录」按钮图标
│   └── missing.png           # 「检查缺失」按钮图标
├── StartMenuBackup.ps1       # 早期命令行版（PowerShell，保留备用）
├── 开始菜单备份工具.bat       # 早期命令行版启动入口
└── backups/                  # 【运行时生成】备份数据目录（请随工具一起拷走）
    └── <时间戳>_build<版本>/
        ├── Start2.bin
        ├── info.json
        └── pinned.json
```

> `backups\` 目录在首次备份后才会出现。**它才是你的布局数据，迁移时千万别漏。**

## 从源码打包 exe

```bash
pip install pyinstaller customtkinter pillow

pyinstaller --noconfirm --clean --onefile --windowed ^
  --name "startmenu_backup" ^
  --icon "icons/app_icon.ico" ^
  --add-data "icons;icons" ^
  --collect-all customtkinter ^
  --exclude-module tkinter.test ^
  startmenu_gui.py
```

要点：
- `--add-data "icons;icons"` 把图标资源打进 exe（否则运行时会因找不到图标而崩溃）。
- `--icon` 设置 exe 本体的图标。
- `--collect-all customtkinter` 收集 customtkinter 的主题资源。
- `--windowed` 去掉控制台黑框。

## 常见问题

**Q：备份列表是空的 / 提示未找到布局文件？**
A：先正常打开一次开始菜单，让系统生成 `Start2.bin`，再点备份。

**Q：恢复后布局没变？**
A：恢复会自动重启资源管理器。若仍未生效，可手动注销 / 重启一次；也可从生成的 `rollback_` 回退点还原。

**Q：「检查缺失」提示该备份没有应用清单？**
A：那是**旧版本备份**（当时还没有清单功能）。请用当前版本重新备份一次，新备份会自动附带 `pinned.json`。

**Q：跨大版本（如 23H2 备份恢复到 24H2）能恢复吗？**
A：可以尝试，但 `Start2.bin` 对系统版本敏感，跨版本可能不完全生效。工具会先弹窗警告；建议同版本（如 26100 → 26100）之间恢复最稳妥。

**Q：为什么恢复后有些磁贴是灰的？**
A：说明对应软件还没装。点「检查缺失应用」拿到清单，把软件装好即可点亮。

## 注意事项与边界

1. **布局文件不包含应用本体。** 重装后需先装回软件，再执行「恢复」，布局才会完整呈现。
2. **系统内置应用不会缺失。** Edge、记事本、计算器、截图工具、此电脑、管理工具等由系统自带，核查时会归入「已存在」。
3. **商店 UWP 应用无法用路径判定**，统一归入「需手动确认」，请自行核对。
4. **`backups\` 目录请随工具一起迁移**（U 盘 / 网盘），只拷 exe 会丢失布局数据。
5. 恢复操作会短暂结束 `explorer.exe`（桌面会闪一下并自动恢复），属正常现象；操作前请保存好正在编辑的内容。
6. 本工具仅适用于 **Windows 11**（`Start2.bin` 机制为 Win11 独有）。
